Shared components

Reference for everyone building WMS pages. Reuse these exact pieces so all pages look and behave the same (NFR-18). Everything lives in assets/wms.css and assets/wms.js.

1. Shell (built automatically)

Set two attributes on <body> and include assets/wms.js. The script adds the navy top bar (WMS logo, the user's name and role, the bell with the inbox panel, Log out) and the folder-style tabs for that role. The active tab joins the white content panel below it. The tabs at the top of this page are the staff version.

<body data-group="manager" data-active="manager-allocation"> <main id="main"> ...your page... </main> <script src="assets/wms.js"></script> </body>

data-group: staff | manager | admin. data-active: the nav key from NAV in assets/wms.js. Manager and IT Admin versions:

Manager tabs

OverviewAllocationCoverageTimetableRequestsSwaps & Stand-insLeave Records

IT Administrator tabs

AccountsRoles & PermissionsAudit Log

2. Buttons and their order

Same label for the same action everywhere. Order in every button row: secondary (Cancel, Close, Dismiss) on the left, the main action on the right. Destructive actions use the red outline.

<div class="actions"><button class="btn">Cancel</button><button class="btn primary">Save</button></div>

3. Status labels (NFR-07: colour always with text)

PublishedTentativeCompletedOn duty nowOver 40 hApprovedRejectedPending Manager approval
<span class="chip ok">Approved</span> <span class="chip err">Rejected</span> <span class="chip tentative">Tentative</span>

Colour use: navy and blue for structure and main actions, green for available and approved, amber for tentative and warnings, red for errors, rejections and destructive actions, coral only for the logo and notification badge.

7. Notifications (bell and inbox panel)

The bell is part of the shell. To send a notification to someone (shown next time they open any page):

WMS.notify('Your roster for 07 – 13 Dec 2026 has been published.', 'nur.aisyah'); WMS.openInbox();

8. Prototype controls

Buttons that switch a page into states that depend on time or other people (after the cutoff, 24 hours later). They sit below the page in a dashed box and are not part of the design: crop them out of report screenshots.

WMS.controls([ { label: 'Simulate cutoff passed', pressed: false, onClick: function () { /* change state */ return true; } } ]);
